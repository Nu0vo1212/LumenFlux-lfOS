# lfOS 性能调优说明（v0.0.2）

所有调优项都经实测验证，不做"抄来一堆参数"式的堆砌。

---

## 网络

| 参数 | 值 | 理由 |
|---|---|---|
| `net.core.somaxconn` | 8192 | accept 队列，突发连接承载 |
| `net.ipv4.tcp_max_syn_backlog` | 8192 | 半连接队列 |
| `net.core.netdev_max_backlog` | 16384 | 高 PPS 下减少丢包 |
| `net.core.netdev_budget` | 600 | 单次软中断处理包数 |
| `net.core.rmem_max` / `wmem_max` | 16MB | 匹配高带宽链路 |
| `net.ipv4.tcp_fastopen` | 3 | 客户端+服务端都开，省一个 RTT |
| `net.ipv4.tcp_tw_reuse` | 1 | TIME_WAIT 复用 |
| `net.ipv4.tcp_fin_timeout` | 15 | 短连接密集服务受益明显 |
| `net.ipv4.tcp_slow_start_after_idle` | 0 | 长连接空闲后不重新慢启动 |
| `net.ipv4.ip_local_port_range` | 10240-65535 | 扩大可用端口 |
| `net.netfilter.nf_conntrack_max` | 262144 | 避免 NAT 表满丢包 |

拥塞控制 **BBR** + qdisc **fq**（已是默认）。
TCP Fast Open、`tcp_syncookies`、`tcp_mtu_probing` 也已启用。

## 内存与文件系统

| 参数 | 值 | 理由 |
|---|---|---|
| `vm.swappiness` | 10 | 服务器内存用途明确，不轻易换出 |
| `vm.dirty_ratio` | 20 | 写多场景减少回写频率 |
| `vm.dirty_background_ratio` | 5 | 后台回写起点 |

| `fs.file-max` | 2097152 | 高并发常见瓶颈 |
| `fs.inotify.max_user_watches` | 524288 | 开发/构建场景 |

## 磁盘

- **I/O 调度器 `none`**：虚拟机上底层调度由宿主机完成，
  客户机再用 mq-deadline 等于多做一层排序，只增加 CPU 开销。
- **挂载参数 `noatime`**：服务器读远多于写，省掉访问时间的元数据写入。

> ⚠️ 注：lfOS **没有 udev**，所以这两项是在 `init` 里**直接写 `/sys`** 实现的，
> 而不是靠 udev 规则 —— 写在 `/etc/udev/rules.d/` 里的规则永远不会被执行
> （实测确认过：`udevd` / `udevadm` 都不存在）。

## 内存水位线：一个真实的权衡

`vm.min_free_kbytes` 由 `init` **按实际内存动态计算**
（取内核默认公式 `sqrt(lowmem_kb * 16)`，2GB 机器算出约 5.6MB），
但启动后你会看到它被抬到约 45MB：

```
khugepaged: raising min_free_kbytes from 5703 to 45056
            to help transparent hugepage allocations
```

**这是开启透明大页（THP）的固定代价，不是配置错误。**

| 选择 | 收益 | 代价 |
|---|---|---|
| **开 THP** | 大页分配顺畅，TLB 命中更好 | 预留约 44MB（2GB 机器） |
| **关 THP** | 省下这 44MB | 失去大页收益 |

lfOS 选择**保留 THP** —— 服务器上数据库/JVM 类负载受益明显。

## 配置位置

| 文件 | 作用 |
|---|---|
| `/etc/sysctl.d/99-lfos.conf` | 安全加固（`kptr_restrict`、`rp_filter`、`syncookies` 等） |
| `/etc/sysctl.d/99-lfos-perf.conf` | 性能调优（本文档描述的项） |
| `/sbin/init` | 遍历加载 `sysctl.d/`、设置调度器与水位线 |
| `/etc/fstab` | 根分区挂载参数 |

### 加载顺序（重要）

`init` **遍历加载整个 `/etc/sysctl.d/` 目录**（按字典序），不是只读某一个文件。

> 踩坑记录：原先 `init` 里硬编码只加载 `99-lfos.conf` 一个文件，
> 后来新增的 `99-lfos-perf.conf` 就怎么都生不效 —— 排查半天才发现
> 根本从未被读取。改成遍历目录后，往 `sysctl.d/` 里丢新文件即可，无需再改 init。

## 一个值得记录的陷阱

用 `chroot` 校验 sysctl 配置时，**务必知道 chroot 里挂的是构建机的 `/proc`**。

我曾因此被误导：`kernel.unprivileged_bpf_disabled` 在构建机的 `/proc/sys/kernel/`
下**存在**（构建机内核有 BPF），于是校验通过；但在 lfOS 上**不存在**
（`CONFIG_BPF_SYSCALL` 未启用），导致 `sysctl -p` 每次启动都返回非 0。

**校验目标机配置，只能在目标机上做。**
